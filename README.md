# ⚔️ 양호후환 전투 시스템

**d100 판정 기반의 턴제 전투 계산 시스템**

캐릭터의 스탯을 기반으로 전투를 자동 계산하고 결과를 시뮬레이션할 수 있는 프로그램입니다.
**설치 불필요! 브라우저만 있으면 바로 사용 가능합니다.** 🎮

## 🎮 주요 기능

### ⚔️ 전투 시스템
- **d100 판정 시스템**: COC 방식의 확률 기반 전투
  - 공격 성공: 주사위(1~100) ≤ 공격력 → 성공
  - 회피 판정: 주사위 ≤ 회피율 → 회피
  - 크리티컬: 주사위 ≤ 크리티컬확률 → 1.5배 피해
  - 성공 등급: 일반 성공, 어려운 성공, 극단적 성공, 대성공

### 👤 캐릭터 관리
- 기본 캐릭터 프리셋 제공
- 커스텀 캐릭터 생성/수정/삭제
- **브라우저 메모리 + Firebase 자동 저장**
- JSON 파일로 내보내기/불러오기

### 🎯 팀 전투
- 히어로 vs 정부 vs 빌런 3팀 구성
- 1:1 또는 팀전 모드 선택
- 실시간 전투 로그
- 전투 기록 저장 및 조회

### 🔐 사용자 인증
- Firebase Authentication (이메일/비밀번호)
- Google 로그인
- 다중 기기 데이터 동기화

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Hosting**: Firebase Hosting
- **Version Control**: Git & GitHub

### 💾 캐릭터 저장 방식
- **자동 저장**: 만든 캐릭터는 브라우저에 자동 저장됨
- **브라우저 변경 시**: 같은 브라우저에서만 유지됨
- **모든 기기에서 사용**: JSON 파일로 내보내서 옮기기 가능

## 📖 사용 방법

### 1️⃣ 캐릭터 선택
- **팀1**과 **팀2**에서 캐릭터 선택
- 같은 캐릭터를 여러 번 선택 가능
- 커스텀 캐릭터도 생성 가능 (+ 버튼)

### 2️⃣ 전투 시작
- "전투 시작" 버튼 클릭
- 자동으로 첫 번째 턴 시작

### 3️⃣ 행동 선택
각 캐릭터는 3가지 행동 중 선택:

- **공격 (💥)**: 대상에게 공격
  1. d100 판정으로 공격 성공 여부 결정
  2. 성공 시 회피 판정
  3. 회피 실패 시 크리티컬 판정
  4. 최종 데미지 계산 및 적용

- **방어 (🛡️)**: 방어 자세
  - 현재 턴에만 받는 피해 50% 감소
  - 턴 종료 후 해제

- **궁극기 (⭐)**: 강력한 공격
  - 무조건 명중
  - 기본 피해의 2배
  - 크리티컬 보너스 적용

### 4️⃣ 전투 결과
- 모든 로그를 텍스트로 확인
- "로그 복사" 버튼으로 클립보드에 복사 가능
- 드래그로 선택해서 복사도 가능

## 💾 캐릭터 관리

### 자동 저장 ✅
- 만든 캐릭터는 **자동으로 저장**됨
- 프로그램을 닫았다 다시 열어도 그대로 있음

### 내보내기 (다른 사람과 공유)
```
왼쪽 사이드바 → "📥 캐릭터 내보내기" 
→ combat_characters_[숫자].json 파일 다운로드
```

### 불러오기 (다른 사람 캐릭터 사용)
```
왼쪽 사이드바 → "📤 캐릭터 불러오기"
→ JSON 파일 선택 → 로드됨!
```

#### 더 쉬운 불러오기 (서버/비용 없음)
- 화면 아무 곳에나 JSON 파일을 "드래그 앤 드롭"하면 즉시 불러옵니다.
- 클립보드에 JSON 텍스트가 있으면 빈 곳에 "붙여넣기(Ctrl+V)"로도 불러올 수 있습니다.
  - 입력창에 커서가 있는 경우엔 붙여넣기 불러오기가 동작하지 않습니다.
  - 불러오면 현재 데이터가 대체되니, 필요 시 먼저 저장해 두세요.

### � 클립보드 복사 (파일 없이 간편 공유)
- **전체 데이터 복사**: 캐릭터 관리 영역의 [📋 복사] 버튼 클릭
  - 모든 캐릭터 + 전투 기록을 JSON으로 클립보드에 복사
  - 메신저/메모장에 붙여넣기 후 전달 가능
  - 받는 사람은 복사한 텍스트를 빈 화면에 Ctrl+V로 적용

### 🎯 전투별 변화만 공유 (충돌 방지)
전투 기록 페이지에서 특정 전투의 변화만 내보내기/복사 가능:
- **변화 내보내기**: JSON 파일로 저장
- **변화 복사**: 클립보드에 복사 (파일 없이 전달)

변화 패치(delta)에 포함되는 내용:
- ✅ HP 변화 (before → after)
- ✅ 스탯 변화 (공격/방어/민첩/스킬/상태)
- ✅ 궁극기 사용 여부

**안전 적용**: 현재 HP가 패치의 before 값과 일치할 때만 적용됩니다.
- 다른 사람이 이미 다른 전투를 진행했다면 자동으로 건너뜀(충돌 방지)

### �💡 여러 브라우저 사용 시
- Chrome에서 만든 캐릭터는 Chrome에만 저장됨
- 다른 브라우저(Edge, Firefox)에서는 별도 저장됨
- **모든 브라우저에서 사용하려면**: 내보내기로 JSON 파일 생성 후 각 브라우저에서 불러오기

## 📊 데미지 계산 공식

### 기본 공격
```
기본 데미지 = (공격력 - 방어력) + 랜덤(0~20)
최종 데미지 = 기본 데미지 × (크리티컬? 1.5 : 1)
```

### 방어 중
```
최종 데미지 = 계산된 데미지 × 0.5
```

### 궁극기
```
기본 데미지 = (공격력 × 1.5 - 방어력) + 랜덤(0~30)
최종 데미지 = 기본 데미지 × 2
```

## 🎲 판정 시스템 (d100)

### 공격 판정
- **대상**: 공격자
- **기준**: 공격력
- **결과**: d100 ≤ 공격력 → 성공

### 회피 판정
- **대상**: 방어자
- **기준**: 회피율
- **결과**: d100 ≤ 회피율 → 회피 성공

### 크리티컬 판정
- **대상**: 공격자
- **기준**: 크리티컬확률
- **결과**: d100 ≤ 크리티컬확률 → 크리티컬

## 🔧 커스터마이징

### 캐릭터 스탯 조정

`js/app.js` 의 `loadDefaultCharacters()` 메서드에서 기본 캐릭터 수정 가능:

```javascript
new Character('캐릭터명', hp, 공격력, 방어력, 회피율, 크리티컬)
```

### 데미지 계산 변경

`js/combat.js` 의 `performAttack()` 메서드에서 수정 가능:

```javascript
result.baseDamage = Math.max(5, (공격력 - 방어력) + 랜덤값);
```

### 스타일 변경

`css/style.css` 에서 색상, 레이아웃 등 변경 가능

## 🐛 주의사항

- **주사위**: 1~100 범위 (0은 나오지 않음)
- **최소 피해**: 5 이상 (방어력이 높아도 최소 피해 적용)
- **체력**: 0 이하로 내려갈 수 없음
- **브라우저**: 최신 브라우저 권장

## � 추천 팀 구성

### 1️⃣ 강한 팀 (공격형)
- 공격력 70 이상의 캐릭터들
- 단점: 방어력이 낮음
- 추천 캐릭터: 마법사, 도적, 소서러

### 2️⃣ 견고한 팀 (방어형)
- 방어력 40 이상의 캐릭터들
- 장점: 오래 버팀
- 추천 캐릭터: 전사, 팔라딘

### 3️⃣ 균형잡힌 팀 (추천 🌟)
- 다양한 역할의 캐릭터 조합
- 예: 검사 + 성직자 + 궁수
- 가장 전략적이고 재미있음

### 4️⃣ 회피형 팀
- 회피율 30% 이상
- 맞지 않으면 피해 안 입음
- 추천 캐릭터: 도적, 궁수

## 🐛 문제 해결

### 🔴 파일이 열리지 않음
- **해결**: 최신 브라우저 사용 (Chrome, Firefox, Edge)

### 🔴 저장된 캐릭터가 사라짐
- **원인**: 브라우저 캐시 삭제
- **해결**: 미리 내보내기로 JSON 파일 저장

### 🔴 파일이 안 불러와짐
- **확인**: JSON 파일 형식 확인
- **해결**: 올바른 파일 선택

## 🎓 개발자용 정보

### 코드 수정하기
모든 코드에 **상세한 주석**이 있어서 쉽게 수정 가능합니다.

예: 공격력 조정
```javascript
// js/combat.js 에서
result.baseDamage = Math.max(5, (공격력 - 방어력) + Math.floor(Math.random() * 20));
// 숫자 20을 조정하면 피해 범위 변경
```

### LocalStorage 확인
브라우저 개발자 도구 (F12)에서:
1. Application 탭
2. LocalStorage 선택
3. combatCalcCharacters 확인
